# AlmaMesh v0.4.0 — your data is portable, the AI is honest

*Released 2026-07-11 · [full changelog](../../CHANGELOG.md)*

## TL;DR

v0.4.0 is the "trust hardening" release. Your data becomes portable
(Backup & Restore moves everything between browsers in one file), the AI
story becomes honest end-to-end (opt-in only, OpenRouter-first setup that
tests itself, billing/model errors that say what's actually wrong, and a
landing page that names the one optional egress), and the app stops needing
a developer nearby: a wedged service worker heals itself, birthplace search
works for places the offline list never heard of, and birth-time
rectification asks about your life warmly instead of clinically.

This is also the first **tagged** AlmaMesh release. Tags v0.1.0–v0.3.0 were
never cut; annotated tagging starts here, forward-only.

## What you get vs v0.3.0

- **Backup & Restore (Spec 061).** Settings → Backup exports profiles,
  charts, members, readings, and settings to a single file; import it in any
  other browser. Client-side only — the file is yours.
- **Rectification, comprehensive (Spec 062).** D9-lagna signals, deeper dasha
  keys, a labeled score anatomy with honest qualitative bands, a per-event
  evidence story in the wizard, and a report that grows Section XII "Birth
  Time Authority".
- **Opt-in cloud AI, OpenRouter-first.** No AI by default. Opting in gets a
  one-screen OpenRouter setup with test-on-save, a model picker, an AI
  security gate, and live credits surfacing. The experimental on-device
  WebLLM tier shipped mid-cycle and was removed before release — cloud-only
  until on-device quality earns its weight back.
- **The reading, where you are.** The full five-section interpretation
  renders on the dashboard with progressive disclosure, regenerates on
  demand, and every stored reading is provenance-stamped ("Generated by …").
  A "how this reading is made" explainer separates deterministic engine
  output from optional AI narration.
- **Birthplace search that finds your town.** Online-primary geocoding via
  Open-Meteo with the offline city list as fallback, natural-input matching
  (diacritics, state/country qualifiers), and coordinate entry as the last
  resort.
- **Self-healing PWA.** The "site is down" wedge auto-recovers; the bundle
  verify key can never be cache-pinned stale; deep links verify signatures
  correctly.
- **SEO + sharing.** Public routes prerender to real HTML, each with its own
  build-time Open Graph card.

Data compatibility: no storage-format, key, or cache-name changes. Existing
charts, settings, and backups keep working untouched.
